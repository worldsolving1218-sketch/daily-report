# 現場アプリ（作業日報・出面表）

建設業向けの現場入力アプリ。ブラウザだけで動く 1 ファイル構成です。

## 入口

| ファイル | 用途 |
|---|---|
| `index.html` | 作業日報（協力業者用：入力・署名・送信） |
| `admin.html` | 作業日報（元請 / 本社用：受信した日報の確認・印刷） |
| `attendance.html` | 出面表（人工の月間管理・印刷・CSV 書き出し） |

作業日報の 2 つは中身が同じです。何ができるかは、アプリの「設定」に入れる
**アクセスキーの権限**で決まります。

## 作業日報

- 工事番号・常用/請負区分・人工数・残業時間を入力
- 手書きの電子サイン（指・スタイラス・マウス）
- A4 帳票としての印刷 / PDF 出力
- 人工集計 CSV・日報一覧 CSV の書き出し
- 元請への送信と、受け取った日報の取り込み

## 出面表

- 作業員 × 日 の月間表。マス目を押して人工を入力
- スマホ向けの「日別入力」画面（休 / 0.5 / 1 / 1.5 を押すだけ）
- 現場（工事番号）ごと／全現場横断の切り替え
- 日曜・祝日の自動判定（振替休日・国民の休日を含む）
- A4 横 1 枚での印刷、出面表 CSV・明細 CSV の書き出し
- 作業日報の人工データの取り込み（同じ端末なら直接、別端末なら人工集計 CSV 経由）

**ホーム画面に追加**すると、アドレスバーのない全画面のアプリとして開けます。
一度開いたあとは電波の届かない現場でも起動できます。

## データの扱い

- 入力したデータは、その端末のブラウザ内にのみ保存されます
- 作業日報は「送信」を押したときだけ、設定した送信先（各社が用意する集計先）へ送られます
- 出面表はどこにも送信しません。端末を移すときは JSON バックアップを書き出してください
- このリポジトリと GitHub には、現場のデータは一切保存されません
