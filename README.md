# 作業日報

建設業向けの作業日報アプリ。ブラウザだけで動く 1 ファイル構成です。

- 工事番号・常用/請負区分・人工数・残業時間を入力
- 手書きの電子サイン（指・スタイラス・マウス）
- A4 帳票としての印刷 / PDF 出力
- 人工集計 CSV・日報一覧 CSV の書き出し
- 元請への送信と、受け取った日報の取り込み

## 2 つの入口

| ファイル | 用途 |
|---|---|
| `index.html` | 協力業者用（入力・署名・送信） |
| `admin.html` | 元請 / 本社用（受信した日報の確認・印刷） |

中身は同じです。何ができるかは、アプリの「設定」に入れる**アクセスキーの権限**で決まります。

## データの扱い

- 入力中の日報は、その端末のブラウザ内にのみ保存されます
- 「送信」を押したときだけ、設定した送信先（各社が用意する集計先）へ送られます
- このリポジトリと GitHub には、日報データは一切保存されません

送信先を設定していない状態では、すべて端末内で完結します。
